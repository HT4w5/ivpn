# Domain language definitions
### User
#### User
An identity authorized to access the ivpn server.
#### External Identity
Info to authenticate the user from an external source.

### Access
#### Key

### ACL
Access control list.
#### Rule
The basic unit of decision. Consists of Action, Protocol, IPs and Ports.

#### Protocol
Transport layer protocols supported by ivpn.

#### IPs
Set of IP addresses.

#### Ports
Set of transport layer ports.

#### Action
Accept or Reject.
